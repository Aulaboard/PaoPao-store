# Pao Pao Store

เว็บสโตร์ต้นแบบสำหรับร้านชุดออกกำลังกาย + อาหารเสริม (ภาษาลาว) สร้างด้วย React + Vite + Tailwind

## รันบนเครื่องตัวเอง

ต้องติดตั้ง [Node.js](https://nodejs.org/) (แนะนำเวอร์ชัน 18 ขึ้นไป) ก่อน

```bash
npm install
npm run dev
```

จากนั้นเปิด `http://localhost:5173` (ลิงก์ที่ terminal แสดงให้)

## แก้ไขข้อมูลร้านจากในเว็บเลย (ไม่ต้องแตะโค้ด)

กดปุ่ม **"แก้ไข" (ปากกา)** มุมขวาบนของหน้าเว็บ จะเข้าสู่โหมดแก้ไข ซึ่งสามารถ:

- แก้ชื่อร้าน, ข้อความหัวข้อ hero, แท็กไลน์, ป้ายความน่าเชื่อถือ, ชื่อหมวดหมู่ — คลิกที่ข้อความแล้วพิมพ์ทับได้เลย
- กดไอคอนดินสอบนการ์ดสินค้าเพื่อ **แก้ไขสินค้า**: ชื่อ ราคา ราคาเดิม(ลดราคา) แท็ก คะแนน จำนวนรีวิว สี (เพิ่ม/ลบ/เลือกสี) ขนาดหรือรสชาติ และ **อัปโหลดรูปสินค้า**
- กด **"เพิ่มสินค้าใหม่ในหมวดนี้"** เพื่อเพิ่มสินค้า
- ในฟอร์มแก้ไขสินค้า มีปุ่ม **"ลบสินค้านี้"**

ข้อมูลทั้งหมดจะถูกบันทึกอัตโนมัติไว้ใน **localStorage ของเบราว์เซอร์** (เก็บเฉพาะในเครื่อง/เบราว์เซอร์นั้นๆ ไม่ได้อัปขึ้นเซิร์ฟเวอร์ที่ไหน) กด **"รีเซ็ต"** ในแถบโหมดแก้ไขเพื่อล้างกลับไปเป็นค่าเริ่มต้นในไฟล์ `src/defaultData.js`

> ⚠️ ข้อควรรู้: เพราะข้อมูลเก็บใน localStorage ของเบราว์เซอร์ผู้ใช้แต่ละคน **การแก้ไขจะเห็นเฉพาะในเบราว์เซอร์ที่แก้เท่านั้น** ลูกค้าคนอื่นที่เข้าเว็บจะยังเห็นข้อมูลเริ่มต้นจากไฟล์ `src/defaultData.js` เพื่อให้ทุกคนเห็นข้อมูลเดียวกัน ต้องแก้ไฟล์ `src/defaultData.js` โดยตรงแล้ว deploy ใหม่ (หรือในอนาคตต่อกับฐานข้อมูล/backend จริง)

## แก้ข้อมูลเริ่มต้นถาวรในโค้ด

แก้ไฟล์ `src/defaultData.js` ได้โดยตรง:
- `defaultContent` — ชื่อร้าน ข้อความต่างๆ
- `defaultProducts` — รายการสินค้าเริ่มต้นทั้งหมด

## โครงสร้างโปรเจกต์

```
src/
  App.jsx              หน้าเว็บหลักทั้งหมด (header, hero, กริดสินค้า, ตะกร้า, checkout)
  defaultData.js        ข้อมูลเริ่มต้น (ชื่อร้าน, สินค้า)
  storage.js             บันทึก/โหลดข้อมูลจาก localStorage
  icons.jsx               ไอคอนบาร์เบลที่วาดเอง (SVG) + mapping ไอคอนป้ายความน่าเชื่อถือ
  components/
    EditableText.jsx     ช่องข้อความที่แก้ไขได้ในโหมดแก้ไข
    ProductForm.jsx        ฟอร์มเพิ่ม/แก้ไขสินค้า (รูป, สี, ไซส์, ราคา ฯลฯ)
```

## Deploy ให้ใช้งานจริง

โปรเจกต์นี้เป็น static site ธรรมดา (`npm run build` จะได้โฟลเดอร์ `dist/`) สามารถ deploy ฟรีได้ที่ Vercel, Netlify, Cloudflare Pages หรือ GitHub Pages — เชื่อม GitHub repo แล้วตั้งค่า Build command เป็น `npm run build` และ Output directory เป็น `dist`

## สิ่งที่ยังไม่มี (ต้องทำต่อสำหรับร้านค้าจริง)

- **ระบบชำระเงินจริง** (พร้อมเพย์/บัตร) — ต้องต่อ payment gateway ผ่าน backend
- **ฐานข้อมูลกลาง** ที่ทุกคนเห็นข้อมูลเดียวกัน (ตอนนี้การแก้ไขอยู่แค่ในเบราว์เซอร์ผู้แก้)
- **ระบบยืนยันตัวตนแอดมิน** — ตอนนี้ปุ่ม "แก้ไข" เปิดให้ทุกคนที่เข้าเว็บกดได้ ก่อนขึ้นเว็บจริงควรซ่อนปุ่มนี้หรือใส่รหัสผ่านป้องกัน
